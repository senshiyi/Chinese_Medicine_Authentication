# 使用指南：骨碎补实验闭集真伪鉴别

当前版本提供命令行，以及可复用于程序的 `InferenceService` Path/bytes、JSON 原生类型接口。**当前没有浏览器页面或 HTTP 服务**；正式开放集 Web/API 模式仍关闭。

> 本系统只做本数据集定义范围内的实验闭集二分类，不能证明 unknown 拒识能力，不能替代专业鉴定，也不能作为医疗、安全、功效或药材质量结论。

## 1. 环境预检

本项目 Windows 虚拟环境的实际解释器是 `.venv\python.exe`，不是 `.venv\Scripts\python.exe`。在仓库根目录执行：

```powershell
cd E:\Desktop\WorkSpace\Chinese_Medicine_Authentication
.venv\python.exe -m pip install -r requirements.txt -e .
.venv\python.exe 项目\Files\doctor.py --json
.venv\python.exe -c "import sys,torch,torchvision; print(sys.version); print(torch.__version__); print(torchvision.__version__); print(torch.cuda.is_available())"
git status --short
```

预期 Python 为 3.11 或 3.12，PyTorch/torchvision 可导入。`doctor.py` 非零退出时先修复报告中的问题。预训练骨干只使用已校验的本地 torchvision 缓存，不会静默联网下载；没有缓存时先显式准备权重，或在新的、受审计配置中将 `model.pretrained` 设为 `false`。

## 2. 真实数据要求

固定原图目录及数量：

- `项目/References/raw/Drynaria_fortunei_authentic/`：335 张 JPEG 正品图。
- `项目/References/raw/Drynaria_fortunei_fake/`：92 张 JPEG 伪品图。
- 427 张图必须分别来自 427 个独立物理样本；不能把同一样本的多角度照片当作独立样本。若今后存在相关批次、来源、设备或拍摄会话，必须共享 `group_id`，防止跨分区泄漏。

标签约束：所有行的 `claimed_herb_name=Drynaria_fortunei`；正品必须为 `actual_species=Drynaria_fortunei,species_annotation_status=verified`；伪品必须保持 `actual_species` 空且 `species_annotation_status=unverified`。伪品实际物种未经检验，禁止依据文件名或模型输出回填物种。

固定切分为 seed 42、`0.70/0.15/0.15`，预期 train/validation/test 为 299/64/64；各自正品/伪品为 235/64、50/14、50/14。test 不能参与训练、早停、选模、调参、阈值选择或温度拟合。

## 3. 闭集实验命令

以下命令均从仓库根目录执行。先为本次不可变实验选择唯一 run ID：

```powershell
$runId = "20260825-drynaria-closed-set-v1"
$runDir = "项目\Results\experiments\drynaria_closed_set\runs\$runId"
```

### 3.1 准备 manifest 与锁定切分

```powershell
.venv\python.exe 项目\Files\prepare_closed_set.py --config 项目\Files\config_closed_set.yaml --check-only
.venv\python.exe 项目\Files\prepare_closed_set.py --config 项目\Files\config_closed_set.yaml
```

`--check-only` 完成同等扫描和校验但不改正式产物。正式命令生成 UTF-8-SIG `metadata.csv`、`train.csv`、`val.csv`、`test.csv`，以及 UTF-8 `splits.json` 和验证报告；必须核对 427 个唯一 `sample_id`、427 个唯一 `group_id` 与上述类别/分区计数。

### 3.2 仅用 train 训练、仅用 validation 选模

```powershell
.venv\python.exe 项目\Files\train.py --config 项目\Files\config_closed_set.yaml --output 项目\Models\experiments\drynaria_closed_set.candidate.pth --device cpu --run-id $runId
```

训练始终写候选路径，不覆盖正式模型。主任务选模分数固定为 `(authenticity_macro_f1 + authenticity_balanced_accuracy) / 2`；claimed/species 指标只报告。当前配置只使用真伪类别权重，`data.use_weighted_sampler=false`，不能同时启用 weighted sampler。

### 3.3 仅用 validation 拟合正温度

```powershell
.venv\python.exe 项目\Files\calibrate.py --mode closed-set-temperature --checkpoint 项目\Models\experiments\drynaria_closed_set.candidate.pth --known-val 项目\Data\experiments\drynaria_closed_set\val.csv --output 项目\Models\experiments\drynaria_closed_set.calibrated.candidate.pth --data-root 项目\References --encoding utf-8-sig --device cpu
```

校准只读取 validation 真伪 logits，拟合一个正温度；不读取 test，也不拟合 unknown 拒识阈值。输出 metadata 必须包含 `experimental_closed_set=true`、`open_set_calibrated=false` 与完整指纹链。

### 3.4 先评估 validation

```powershell
.venv\python.exe 项目\Files\evaluate.py --config 项目\Files\config_closed_set.yaml --checkpoint 项目\Models\experiments\drynaria_closed_set.calibrated.candidate.pth --partition validation --run-dir $runDir --json
```

只有 validation 的 Macro F1、Balanced Accuracy、counterfeit recall 均为有限值且分别不低于 **0.80**，所有关键指纹一致，才允许继续。未通过时保留候选与报告，只能开启新的 validation-only run；不能查看 test 后调参。

### 3.5 locked test 只能执行一次

```powershell
.venv\python.exe 项目\Files\evaluate.py --config 项目\Files\config_closed_set.yaml --checkpoint 项目\Models\experiments\drynaria_closed_set.calibrated.candidate.pth --partition locked-test --run-dir $runDir --json
```

每个 run 最多执行一次。程序在任何 test 推理之前先创建 `locked_test/reservation.json`；即使之后失败，也不得删除 reservation 或重复运行来挑结果。locked test 低于同样的 0.80/0.80/0.80 门槛时保留候选和报告，但禁止晋升，也禁止据此调参。

### 3.6 Path/bytes 预测与条件晋升

```powershell
$smokePath = (Import-Csv -Encoding UTF8 项目\Data\experiments\drynaria_closed_set\test.csv | Select-Object -First 1).image_path
$smokeImage = if ([IO.Path]::IsPathRooted($smokePath)) {
    (Resolve-Path -LiteralPath $smokePath).Path
} else {
    (Resolve-Path -LiteralPath (Join-Path 项目\References $smokePath)).Path
}
.venv\python.exe 项目\Files\predict.py --image $smokeImage --checkpoint 项目\Models\experiments\drynaria_closed_set.calibrated.candidate.pth --device cpu --experimental-closed-set --json
```

仅当 validation 和该 run 的一次 locked test 都通过固定门槛时执行：

```powershell
.venv\python.exe 项目\Files\promote.py --config 项目\Files\config_closed_set.yaml --run-dir $runDir --candidate 项目\Models\experiments\drynaria_closed_set.calibrated.candidate.pth --smoke-image $smokeImage
```

晋升命令会安全加载候选、校验 schema/哈希/报告/门禁，比较同一图片的 Path 与 bytes JSON，再把候选复制到目标同目录临时文件并用 `os.replace` 原子替换。训练、校准和评估都不会覆盖正式模型。

## 5. 输出文案与概率含义

批准的三类模板（百分比随当前结果变化）：

- 正品：`此药品为正品，有91.0%的可能该药材为正品。`
- 物种已核验的伪品：`此药品为伪品，有93.0%的可能该药材为伪品，声称为‘当归’，实际应为‘欧当归’。`
- 本数据集伪品物种未核验：`实际药材无法确定，有93.0%的可能该药材为伪品，请人工复核。`

百分比是 validation 温度校准后的**闭集模型概率**，只在“本数据集正品/伪品二选一”条件下解释；它不是视觉相似度、unknown 概率、医学确定性、质量合格率或模型整体准确率。单张图片的 93.0% 置信度不等于模型有 93.0% 准确率；整体性能只能从独立 validation/locked-test 报告及其区间读取。

JSON schema v1 必须保留 `experimental_closed_set=true`、`open_set_calibrated=false`、`scope_warning`、两类概率与模型/数据/切分指纹，供审计使用。

## 6. 编码与闭集限制

源码、JSON、YAML、Markdown 使用 UTF-8，CSV 写为 UTF-8-SIG。各 CLI 通过现有 `configure_utf8_stdio()` 配置中文标准流；读取 CSV 时默认兼容 UTF-8-SIG，并保留 GBK 回退与警告。出现乱码时不要改标签内容，先检查终端和文件编码。

当前数据没有 unknown calibration/test，也没有伪品实际物种检验；背景、包装、批次、来源、设备和拍摄会话信息不足，仍可能存在采集偏倚。即使三个门槛全部通过，也只表示该固定闭集实验满足预注册工程门禁，不代表开放世界泛化、药典鉴定、临床适用或质量认证。

## 7. 未来 Web 适配示例

未来 HTTP 适配器可在进程启动时加载一次服务，并把上传 bytes 传给同一个安全推理边界：

```python
service = InferenceService.from_checkpoint(MODEL_PATH, device="cpu")
payload = uploaded_file.read()
response = service.predict_experimental_closed_set(payload).to_dict()
return JSONResponse(response)
```

上传大小、MIME 白名单、身份认证、授权和 rate limit 属于未来 HTTP adapter；它们必须额外执行，不能削弱或绕过 `InferenceService` 已有的 bytes 大小、像素数、解码后内存和安全解码限制。适配器应原样返回 JSON 原生字段及领域错误，不重新计算概率或改写结论。本版本没有监听端口，访问 `localhost` 失败是预期行为。
